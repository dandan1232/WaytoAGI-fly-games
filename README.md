## 玩法

你是摩天楼外的小小清洁工。鼠标指向水流方向，按住左键喷水，角色会被反冲力推向反方向。向左下喷水，角色向右上飞；落在黄色平台上松手即可补水。

- 键盘：方向键指定水流方向、空格喷水，P / Esc 暂停，M 切换音效，R 打开重玩确认。
- 手机：拖动右下摇杆指定水流方向，松手停止。
- 空调需要绕开，水流能清除污渍和泥团；洗亮特殊窗户可发现四位住户。
- 水用尽后落在空调外机上，本次飞行失败；可点击「重新起飞」或按 R 从头再试。空中断水、侧面擦碰不会立即失败，空水落到黄色平台仍可补水。
- 落在楼顶即通关；洁净度达到 35%、发现至少三位住户可分别获得额外一星。
- 掉落或手动救援返回最高补水点，保留本局清洁进度。结算可下载飞行纪念海报。
- 彩蛋：洗亮写着「请勿打扰」的脏窗，可发现泡澡的小黄鸭、解锁「原来你在摸鱼」。成就保存在当前浏览器；重玩后仍可再次发现。

## 本地开发

需要 Node.js 22.14+、npm。

```sh
npm ci
npm run dev
npm test
npm run check
npm run build
npm run test:e2e
npm run test:ui
npm run test:production
```

浏览器验收使用电脑已安装的 Google Chrome；`playwright.config.ts` 会启动本地开发服务器。游戏运行不依赖 CDN、外部字体、模型服务、账号或后端。音效默认为关闭，个人最佳仅保存在当前浏览器。
