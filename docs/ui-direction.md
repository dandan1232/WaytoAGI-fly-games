# R3 界面重做：清洗机的工业感与街机首屏

用户反馈：现有前端呈现出明显的通用 AI 模板感，要求使用 UI 技能改进。使用 frontend-design 与 ui-ux-pro-max；先检查原界面，再确定以下设计方向。

## 诊断与选择

旧版将胶带便签、倾斜卡片、圆角仪表、徽章、英文小标题和装饰性口号同时放在首屏，造成竞争。新版由卡赫黄与黑色产品机身出发，用大色块、清楚的中文标题和真实游戏画面建立识别。唯一主要视觉手法是黄色首屏的斜切边缘与反向水流，让“反冲力”成为画面的一部分。

技能数据库首次将 arcade 匹配到 Pixel Art，红蓝霓虹与本项目图样不符，未采用。收窄查询 industrial functional minimal 后返回 minimalism-and-swiss-style；仅采用功能优先、清楚层级、单一强调色和减少装饰的原则，不套用新闻排版或企业落地页结构。

## 设计约定

- 卡赫黄 `#FFDA00`：首屏主色、关键操作与补水状态。
- 机身黑 `#1D2223`：文字、主要按钮与功能控制。
- 白 `#FFFFFF`：功能面板与弹窗。
- 冷雾灰 `#E6EEF0`：游戏背景；钢灰 `#566269`：次要文字；水蓝 `#2B778E`：水量。
- 标题使用系统中文粗黑体；拉开标题与正文的尺寸差。正文 Segoe UI / Microsoft YaHei；游戏数字 Bahnschrift / Consolas，使用等宽数字。无需外部字体。
- 所有文字表达玩法或状态，删除仅装饰的英文栏目、招募话术、胶带、印章和营销口号。
- 主要操作为黑底矩形按钮，功能按钮至少 44×44 CSS px，显式焦点、按下反馈和减少动态效果支持。
- 桌面使用左侧黄底标题、右侧游戏场景；手机使用紧凑的黄色上部与下部场景。产品图为无边框陈列。
- HUD 合并为一个仪表区域，避免多个浮动卡片；手机用顶部紧凑信息条，保留中部窗口视野与底部触摸操作区。

桌面：`[ 标题 / 一句操作 / 开始 ] 斜切 [ 真实场景与喷水角色 ]`，装备陈列位于标题下方。

手机：`品牌与功能 → 标题与开始 → 实际游戏场景 / 小幅装备标注`；进入游戏后 `顶部状态 → 楼面 → 底部摇杆与救援`。

## 验收

检查首屏、进行中、暂停、说明、成就、终局与成绩单的统一性；320px 手机、390px 触摸、平板与桌面无横向溢出；操作按钮、装备图、焦点和弹窗不互相遮挡。回归真实鼠标完整通关、触摸和彩蛋收藏，构建通过后独立 commit/push，更新原 Vercel 链接并做匿名生产验证。
