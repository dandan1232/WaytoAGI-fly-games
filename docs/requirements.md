# 我靠洗地飞起来了 — 产品需求 v1

## 意图与范围

以德国卡赫 brief 的「清洁侠宇宙」「解压爽感」「清洁一平方米，点亮一座城」为创意来源，制作打开链接即可玩的网页小游戏。主体验是水枪反冲力驱动的空中跑酷，喷水同时影响位移、洁净度和水量。游戏采用夸张幻想设定，不宣称真实清洗机能载人飞行，不用于指导高空作业。

首版是一栋可完整通关的楼，约 3–5 分钟，含三个高度区段、多个可落脚补水平台、空调障碍、泥团与四位可解锁住户。无需登录、付费、网络 API 或下载。上线目标为公开可访问的 Vercel 地址。源码目录为 `D:\Code\WaytoAGI-fly-games`。

## 玩家体验

1. 首屏展示实际游戏建筑和角色，标题「我靠洗地飞起来了」，一句话说明「往下喷，往上飞」。点击「开始起飞」进入游戏。
2. 角色从楼底补水站起步。喷射方向和反冲力相反，向下喷水可升空，斜喷可左右移动。松开停止喷水并受重力下落，没有独立跳跃键。
3. 水流击中立面会清除对应位置污渍；水量持续消耗，落在黄色补水平台后自动补充。平台更新安全绳检查点，跌落后回到最近检查点，不丢失已清洁区域。
4. 水流可冲散泥团，空调实体会阻挡移动。清洁特定窗户会解锁原创住户及一句笑话。集齐四位住户作为可选目标，不强制玩家清空整面楼。
5. 到达楼顶即可通关。镜头拉远，展示实际清洁轨迹与藏在楼面下的完整「向上飞」主题画作，并明确区分玩家清洁区域和结局艺术展示。
6. 结算展示最高高度、洁净度、住户数、用时、救援次数，按固定规则给出星级。支持重玩与下载本局纪念海报；本地保存最佳结果，存储不可用时不阻断游戏。

## 操作与设备

- 桌面：鼠标指向喷射方向，按住左键喷水；也可用方向键指定喷射方向、空格喷水。提示明确「箭头表示水流方向，角色朝反方向飞」。
- 手机：右下方虚拟摇杆直接控制喷射方向，按住偏移即喷水，松手停止。默认摇杆向下为上升，操作区禁止触摸滚屏，页面其他区域仍可正常使用。
- Esc / P 暂停；R 请求重新开始；M 切换音效。按钮均可通过键盘访问。切走页面或窗口失焦自动暂停并清除输入，返回后手动继续。
- 至少验证 390×844、768×1024、1440×900；支持浏览器缩放，按钮触控区域不小于 44px。减少动态效果偏好关闭镜头晃动与非必要粒子。

## 可玩性边界

- 洁净度以关卡生成的全部污渍单元初始厚度总和为分母，实际移除厚度为分子；结局自动画作揭晓不计入。
- 住户窗格范围清洁达到 60% 解锁。通关一星，洁净度达到 35% 加一星，至少三位住户加一星。最佳记录依次比较星级、洁净度、住户数量、较短用时。
- 检查点只向更高位置更新；手动和跌落救援均计数，恢复到最高补水检查点并补满水，提供无惩罚的学习空间。

- 固定时间步长，30 / 60 / 120 fps 下物理行为保持一致；限制单帧累计时间，避免页面恢复导致穿模。
- 水量不为负、无水不产生推力、补水有速率；可达平台间的高度差必须低于满水可达高度。
- 角色与平台/空调碰撞分离；下降落脚、侧面阻挡、顶部碰撞均有规则。
- 掉落可恢复、暂停不推进计时、重开完全重置本局而保留最高纪录。
- 游戏数据均为娱乐指标，绝不换算真实产品水压、效率或节水数据。

## 不做的内容

首版不接用户账号、真实排行榜、多人联机、模型 API、付费功能或真实设备控制。品牌名称用文字呈现，角色、立面、住户、音乐由代码原创；不冒用官方授权。后续才考虑更多楼宇、竞速幽灵和关卡编辑器。

## 项目约定

用户已授权自主 commit、push、创建 PR 和合并，以及先部署到 Vercel。每次提交只包含当前验收点已验证内容，不以未验证进度宣称完成。远端与部署账号使用现场认证结果，不猜测账号归属。`girllme` 指技能，非账号。

## R1 — 产品外形还原

用户补充产品图样后，要求重新生成装备且外形相似。以所提供的 KHB AIR 无线折叠清洗机图样为准：黑色圆筒机身、黄色细长折叠握柄、黑色背脊、椭圆按钮、短粗旋转喷头、白底卡赫铭牌。首页和游戏内使用同一份参照图生成的透明素材；角色背包为浅蓝色游戏补水箱，视觉上与真实产品区分。不得将 KHB AIR 画成通用黄色水枪、长管高压枪或带大电池座的电钻。验收包括原图对照、桌面/手机布局、喷口对齐和原有完整通关流程回归。通过后独立 commit + push。

## R2 — 脏窗隐藏成就

起点附近一扇「请勿打扰」窗户藏着泡澡的小黄鸭。玩家必须用实际水流洗掉该窗格至少 70% 的污渍，才会揭晓彩蛋并解锁「原来你在摸鱼」。局部进度来自原有污渍网格，不按点击、游戏时长或登顶奖励触发。发现后出现成就卡与音效（仅已开启音效时）、HUD 收藏标记、结算说明；本局解锁也印入纪念海报。

每局只发出一次发现事件，救援保留发现状态。收藏使用独立本地存储，刷新和重玩后仍保留；新一局的窗户重新变脏，重新洗净提示「彩蛋再次发现」。存储受限时仍可正常解锁并明确提示未保存。彩蛋不改变通关、住户数量或星级条件。验收包括鼠标与触摸真实喷水、重复触发控制、救援/重玩/刷新、无法存储和原有完整通关回归。通过后独立 commit + push 并更新原 Vercel 地址。

## R3 — 界面设计重做

用户要求使用 UI 技能改善通用 AI 模板感。应用 frontend-design 与 ui-ux-pro-max，将界面重做为卡赫黄、机身黑和白色功能界面：首屏采用大色块斜切、清晰的中文标题、主要开始按钮和真实场景的喷水预览；产品图直接陈列。减少装饰卡片、胶带、口号与无功能的英文标签。

桌面 HUD 整合为一组仪表，手机 HUD 放到顶部，保留楼面和彩蛋视野。说明、暂停、成就、成绩单使用一致的排版与按钮。支持至少 320×640、390×844、768×1024、1024×768、1440×900 和 844×390 横屏；开始、说明、音效、救援和摇杆可用、无遮挡；支持减少动态效果与键盘焦点。KHB AIR 参考素材及已有玩法、成就与存档继续有效。设计约定见 `docs/ui-direction.md`；完成视觉与玩法验收后独立 commit/push，更新原生产地址。

## R4 — 空水落在空调上判失败

用户要求水用完后落到空调外机上直接结束本次飞行。判定条件为耗尽可用水量并受到空调顶面的落脚支撑；已有水量时可暂时落脚，在外机上把最后一点水耗尽也会失败。空中水用完、擦碰侧面或底面不直接失败；空水落到黄色补水平台仍可正常恢复。

失败后冻结本局物理、计时和水量，停止喷水、清除触摸与按键输入，显示失败原因、最高高度和本次洁净度。不会记入最佳通关成绩，也不能再通过救援恢复。点击「重新起飞」或按 R 开始新的一局，重置清洁、时间、水量与救援次数，已经收藏的成就仍保留。失败弹窗无法用 Esc 关闭后继续飞行。验证边界条件、事件只触发一次、桌面与触摸真实输入失败/重试，并回归完整通关。
